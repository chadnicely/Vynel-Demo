# 2026-08-23

## New-workspace wizard — Slice 1, the AI seam (from Chad's `design/mission-control-prototype`)

The 13-screen "Walk me through it" wizard starts its move to main. This slice is the engine half:
two best-effort one-shots on the provider contract (`studyRivalSite`, `synthesizeWorkspacePlan`),
their Claude implementations over the existing `runClaudeDistillTurn`, and the two routes under
`/workspaces/wizard`. Note: `docs/module-notes/new-workspace-wizard.md`.

**Learned:**

- **The demo's nouns encode its schema.** "New app", "project inside a workspace", "which account
  builds" all came from the design branch's two-level workspace split and per-project accounts —
  decisions main never took. Kafi's one-line corrections ("it's a new workspace", "accounts are
  global") each collapsed a whole slice of plumbing. Name the entity main actually creates before
  porting a single screen; the route, the SDK namespace and the table name follow from it.
- **Folder first is also a security decision.** Moving the folder pick to screen 1 let the one-shots
  dispatch from the user's own folder instead of the global root dir — and the reviewer's catch is
  worth keeping: a toolless distill still loads that folder's `CLAUDE.md` / `.claude/settings*.json`
  (`settingSources: ['user','project','local']`). Same exposure as opening it as a workspace, but say
  so in the comment rather than claiming "nothing happens there".
- **Root prettier is the web app's style.** `prettier --write` on a package test rewrote it to double
  quotes + semicolons; packages are single-quote/no-semi. The existing package tests all "warn" for
  the same reason — run prettier on packages only with explicit `--single-quote --no-semi
  --print-width 100 --trailing-comma all`, or not at all.
- **A provider-contract method fans out to every inline fake.** Two default-null methods on
  `AiAgentProvider` broke three `as AiAgentProvider` object-literal fakes at typecheck (and the
  branch's own commit had patched exactly those three). Grep `discoverModels: async () => null` for
  the full list; one of them (`providers/index.test.ts`'s degraded provider) spreads
  `makeFakeProvider()` and needs nothing.
- **Don't rename files while the full suite runs.** The first full run reported one red — the SDK
  namespace pin — from the pre-rename `newApp` namespace; the second run, post-rename, was clean.
  Kill or wait, then rename, then run once.
