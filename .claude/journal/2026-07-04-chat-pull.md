# 2026-07-04 — chat vertical-slice (the first substrate beneath @vynel/session)

Started the session keystone and immediately hit the real shape: **`@vynel/session` is the apex of a
stack whose walls aren't in KLONE.** The old `refactor/session-library` branch is mid-migration — it
extracted only the global-root turn *core* + the `SessionSink` contract into `packages/session`; the bulk
(delegation, composers, seeded-swap, resolvers, sinks) still lives across a 28-file `apps/api/src/sessions/`.
And session hard-imports three un-pulled domains: **`chat`** (turn engine + persistence), **`orchestration`**
(delegation), **`session-continuity`** (root↔SDK link). So "build session" = build the stack bottom-up.

**Two decisions with Chad:**
- **Continuity is a *feature of session*, not a separate package** (Chad) — §5 "continuity is intrinsic". It's
  cycle-free because the ONLY thing below session that reaches continuity is the workspace turn-*runner*
  `start-chat-turn` (misfiled in `chat/`), which comes home to `@vynel/session` with the other runners. So
  `chat` = pure persistence; no `session ⇄ chat` cycle. Continuity's 20 files land with the session pull.
- **`root` → `primary`** vocabulary (Chad): a *workspace root* is confusingly both a "root" and a delegated
  child of the *global root*; "primary session per scope" + parent/child edges is cleaner. Applied at the
  session/continuity pull (where `primary_sessions` lands); chat keeps faithful `root` names for now.

**Chat pull (`1568e91`) — hybrid vertical-slice:** schema (3 tables) + repos were already in the kernel →
git-mv'd to `packages/chat/src/{schema,repositories}` (renames, history preserved); logic pulled fresh from
old `packages/core/src/chat`. **Excluded** `start-chat-turn(.test)` — the sole `session-continuity` importer,
relocating to `@vynel/session`. Rewired: `@vynel/core/errors` → `@vynel/errors`; repos → `@vynel/db` +
`../schema/`; hub FKs via `@vynel/db/schema/{users,workspaces}` (memory precedent). **Concern-fold:**
`turn-consumption/` (the `consumeSessionEventStream` engine + handlers + row-builder + title) · `records/`
(delegation/segment writers) · `history/` (session CRUD) · `context/` (the `/context` report). One cross-folder
edge (records → turn-consumption's row-builder). Kernel schema barrel dropped `./chat`; drizzle config repointed
3 paths → `../chat/src/schema/*`.
